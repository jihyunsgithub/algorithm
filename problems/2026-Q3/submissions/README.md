# 풀이 제출 위치

본인의 GitHub ID로 디렉터리를 만든 뒤 다음 이름으로 답안을 추가합니다.

```text
submissions/
  YOUR_ID/
    01-square-regions.py
    01-square-regions.cpp
    02-ticket-exchange.py
    02-ticket-exchange.cpp
```

풀고 싶은 문제와 언어만 제출해도 됩니다. 각 소스는 `solution` 함수를 정의하며 실행용 `main`이나 입력 처리는 필요하지 않습니다. 풀이 설명을 덧붙이려면 같은 디렉터리에 Markdown 파일을 추가하세요.

[제출·검증 방법](../CONTRIBUTING.md)을 읽고 테스트 결과와 함께 PR을 보내주세요.
